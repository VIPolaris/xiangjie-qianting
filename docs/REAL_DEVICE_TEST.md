# 相接浅听 v1.4.0 实机验收

## 准备

1. 确认手机为 Android 16，蓝牙已经保存至少一台车载音响、耳机或音响，并启用“媒体音频”。
2. 在首页点击“增加设备”；已添加设备名称下方应显示完整 MAC 地址，空槽位不应出现。
3. 在“后台”页确认附近设备和通知权限；在系统设置中允许后台运行，建议加入 Android 电池优化白名单。
4. 音乐用例需至少安装 Apple Music、Spotify、QQ音乐、网易云音乐或酷狗音乐之一，登录并准备一个可继续播放的队列；建议授予媒体会话控制授权。

## 图标与界面细节

| 用例 | 操作 | 预期结果 |
|---|---|---|
| 启动图标 | 在启动器、应用信息页和最近任务中查看图标 | 纯白背景与蓝橙矢量主体边缘清晰，无灰白圆盘、位图模糊、阴影或底色差异 |
| 启动器遮罩 | 分别使用圆形和圆角方形启动器图标遮罩 | 双圆主体居中并完整位于安全区，不裁切边缘 |
| 通知图标 | 触发播报或音乐恢复通知 | 显示清晰的无背景双圆单色轮廓 |
| 卡片阴影 | 在浅色、深色模式下逐页查看首页、音频、音乐和后台 | 所有卡片均无投影；卡片仍能通过背景色差清晰分层 |
| 类型来源文案 | 查看已添加设备并点击左上角设备图标 | 卡片不显示“手动选择”“自动识别”或“默认类型”；图标仍能打开类型选择窗口 |
| 无级音量 | 在音频页拖动两条音量滑杆，中途停住后再松手 | 轨道不显示密集刻度点；整数百分比跟随手指实时变化，松手后保存，重启仍为最后数值 |

## 已配对设备、类型与三设备

| 用例 | 操作 | 预期结果 |
|---|---|---|
| 已配对直选 | 选择系统蓝牙中已经保存、当前不可发现的设备 | 列表中可直接选择，不需要解除配对或重新配对 |
| 发现新设备 | 在选择弹窗点击“发现新设备” | 打开系统 Companion 设备选择器，结果写入发起操作的槽位 |
| 动态卡片 | 未添加设备、逐台添加、移除中间设备 | 只显示已添加卡片；未满三台时只有一个“增加设备”按钮 |
| 完整地址 | 查看设备卡片和连接历史 | 始终显示完整标准化 MAC 地址，不出现圆点遮挡 |
| 自动类型 | 分别添加车载音响、耳机和音响 | 左上角显示对应图标；未知类型默认音响 |
| 手动类型 | 点击设备图标并选择另一类型 | 图标立即更新，重启后保留用户选择 |
| 重复设备 | 尝试把相同 MAC 地址再次添加 | 不可选择或明确提示已经占用 |
| 三设备轮流连接 | 依次连接三台播放设备 | 每台均按自己的两个开关运行，同一连接只触发一次 |
| 无关设备 | 连接或断开未配置耳机 | 不触发，也不停止已添加设备正在运行的任务 |
| 快速切换 | 第一台任务运行时把活动 A2DP 路由切到第二台 | 第一台安全停止，第二台按自身配置接管 |
| 移除设备 | 移除正在连接的目标设备 | 对应任务停止，其他设备配置和任务不受影响 |

## 播放组合

| 音频播报 | 播放音乐 | 预期结果 |
|---|---|---|
| 关 | 关 | 只写入连接历史，不启动播放服务 |
| 开 | 关 | 仅播放所选提示音 |
| 开 | 开 | 提示音自然结束后通过当前音乐平台播放音乐 |
| 关 | 开 | A2DP 路由就绪后直接恢复当前选择的平台，不播放提示音、不修改播报音量 |

每台设备均点击“测试此设备”复测其开关组合。关闭两个开关时测试按钮应禁用。

## 连接与历史

| 用例 | 操作 | 预期结果 |
|---|---|---|
| A2DP 未就绪 | 只开启电话音频或关闭媒体音频 | 最多等待 20 秒后取消，手机扬声器无声音 |
| 播放中断开 | 播报或恢复音乐期间断开目标设备 | 立即停止，不从手机扬声器继续 |
| 会话去重 | 同一次连接中重复收到 ACL/A2DP 事件 | 只执行一次 |
| 下次重连 | 完整断开后再次连接 | 创建新连接会话并再次运行 |
| 历史展开 | 点击“最近状态” | 展开最多十条，按新到旧显示设备、完整地址、连接/断开时间和结果 |
| 历史上限 | 连续完成超过十次连接 | 只保留最新十次 |

## 五个音乐平台与强制恢复回归

依次选择 Apple Music、Spotify、QQ音乐、网易云音乐和酷狗音乐；首页设备卡片应统一显示当前平台名称，准备情况应立即切换到该平台。

| 用例 | 操作 | 预期结果 |
|---|---|---|
| 平台切换 | 依次选择五个平台并返回首页 | 选择被持久化，首页与通知均使用当前平台名称，其他设备仍共用同一选择 |
| 安装检测 | 分别选择已安装和未安装的平台 | 准备情况立即刷新；未安装时提供对应安装入口 |
| 未安装平台 | 选择未安装平台后触发 | 明确提示未安装并终止，不自动换到其他已安装平台 |
| 锁屏接续 | 划掉应用、锁屏，再连接启用音乐的设备 | 播报后或仅音乐模式下恢复当前平台原队列 |
| 冷会话/被划掉 | 长时间未打开或从最近任务划掉当前平台 | 依次尝试目标包的专属会话、媒体服务、显式启动和系统播放键 |
| 无声会话 | 当前平台显示播放但蓝牙设备没有声音 | 暂停—播放重建并持续重试，不把会话状态单独当成功 |
| 其他播放器 | 让非目标音乐 App 正在播放后触发 | 暂停误唤醒播放器并继续争取当前选择的平台，不把错误平台当成功 |
| 60 秒模式 | 关闭“持续重试至设备断开”并模拟失败 | 约 60 秒后停止并明确显示未确认出声 |
| 持续模式 | 开启持续模式并模拟失败 | 通知持续显示次数和时间，成功或目标路由断开时结束 |
| 无通知授权 | 撤销通知使用权后连接 | 仍尝试启动和系统播放键，并提示无法精确确认 |
| 平台强停 | 在系统设置中强行停止当前音乐平台 | 不保证恢复；手动打开对应平台后再测 |

## 后台可靠性

1. 分别使用一台有 Companion 关联和一台仅从已配对列表选择的设备测试锁屏连接。
2. 从最近任务划掉应用，锁屏静置至少 30 分钟后连接。
3. 重启手机，不主动打开应用，等待启动完成后连接。
4. 若已配对直选设备锁屏触发失败，先确认 Android 电池优化白名单和系统后台运行权限。

## 失败时收集信息

- 展开首页“最近状态”，截图对应连接记录及“后台”页权限状态。
- 记录设备名称、完整 MAC、连接时间、活动媒体路由和两个设备开关。
- 用 Android Studio Logcat 过滤包名 `com.polaris.caraudiotrigger`。
